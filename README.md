# Rodrigo Pinheiro Ink

Portfólio responsivo para um tatuador de pontilhismo, criado com React e Vite.

## Tecnologias

- JavaScript
- React
- HTML semântico
- CSS responsivo
- Vite

## Como executar

1. Instale o [Node.js](https://nodejs.org/).
2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

4. Abra o endereço mostrado no terminal, normalmente `http://localhost:5173`.

## Build de produção

Para verificar se o projeto está pronto para publicação:

```bash
npm run build
```

O site usa links para WhatsApp e Instagram e contém uma galeria com imagens temporárias. As imagens podem ser substituídas por fotos reais dos trabalhos em `src/App.jsx`.
